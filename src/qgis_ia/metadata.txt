about=QGIS_IA integra IA ao QGIS de duas formas. (1) Painel de chat: descreva a tarefa em linguagem natural e o plugin executa ações predefinidas (camadas, geoprocessamento, layout, expressões). (2) Servidor MCP: expõe o QGIS por Model Context Protocol para o Claude Desktop, Claude Code ou outro cliente MCP operarem o projeto aberto. O servidor escuta apenas em 127.0.0.1, exige token e tem modo somente leitura.
